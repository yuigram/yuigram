# @yuigram/bot-api

The Telegram Bot API subsystem for [Yuigram](https://github.com/yuigram/yuigram): the client,
the generated method surface, polling, webhooks, routing, file downloads and the testing
harness.

**You probably want [`yuigram`](https://www.npmjs.com/package/yuigram) instead** — it is the
package applications install, and it re-exports everything here.

Zero runtime dependencies. MIT.
